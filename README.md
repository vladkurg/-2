# 🧹 Стирка ковров Донецк — Telegram Bot

## 📦 Установка и запуск

### 1. Локальный запуск

```bash
pip install -r requirements.txt
python main.py
```

### 2. Настройка переменных (.env)

```
BOT_TOKEN=ваш_токен_бота
CHANNEL_ID=-100xxxxxxxxx  # ID канала (с -100 впереди)
MANAGER_PHONE=+79780505589
ANTHROPIC_API_KEY=ваш_ключ_claude
```

> ⚠️ CHANNEL_ID должен начинаться с -100, например: -100789115888

### 3. Деплой на Railway

1. Создайте репозиторий на GitHub и загрузите все файлы
1. Зайдите на [railway.app](https://railway.app)
1. Нажмите **New Project → Deploy from GitHub repo**
1. В разделе **Variables** добавьте все переменные из .env
1. Railway автоматически запустит бота

## 👑 Админ-панель

Введите команду `/admin` в боте.

**При первом входе:** создаётся пароль — он сохраняется в базе данных.

**Возможности админа:**

- 📋 Просмотр и управление заявками (смена статуса)
- ⭐ Модерация отзывов (одобрить / отклонить)
- 💰 Изменение цен на услуги
- 🎁 Управление акциями
- 🖼 Добавление фото до/после в галерею
- 📊 Статистика

-----

## 🤖 Функции бота

### Клиентская часть:

- 🧮 **Калькулятор** — расчёт стоимости по размеру ковра
- 📅 **Выбор даты** через встроенный календарь
- 🚚 **Доставка** 500 руб. (бесплатно при заказе от 2000 руб.)
- 📦 **Статус заказа** с уведомлениями
- ⭐ **Отзывы** с системой оценок
- 🖼 **Галерея** фото до/после
- 🎁 **Акции**
- ❓ **FAQ**
- 📞 **Контакт менеджера**

### Канал:

- Авто-публикация одобренных отзывов
- Новости каждые 3 дня (через Claude AI)

## ⚙️ Получение ANTHROPIC_API_KEY

1. Зайдите на [console.anthropic.com](https://console.anthropic.com)
1. Создайте аккаунт
1. Перейдите в **API Keys** → **Create Key**
1. Скопируйте ключ в .env
